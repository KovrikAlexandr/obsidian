Утилита для создания ссылок (как hardlink, так и softlink)

Синтаксис:
```
ln [OPTIONS] TARGET LINK
```
- `TARGET` – файл, на который создаётся ссылка
- `LINK` – имя ссылки
По умолчанию создаётся жёсткая ссылка (hardlink)

Полезные опции:
- `-s` – создать мягкую (символическую ссылку)
- `-f` – force
- `-d` – создать на каталог (только под root)

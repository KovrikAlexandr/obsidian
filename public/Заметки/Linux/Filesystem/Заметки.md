Диск состоит из секторов (sector). Это минимальная структура адресации. 

Секторы могут быть логическими и физическими.
Смотреть через lsblk:
```bash
lsblk -o NAME,PHY-SEC,LOG-SEC
```

Раздел (partition) – логический кусок диска. Диапазон секторов
Вначале диска есть таблица разделов (GPT или MBR)

На разделе уже можно создать файловую систему. Файловая система состоит из блоков
Размер блока – аттрибут файловой системы. Блок не может быть меньше сектора (сектор – минимальная единица адресации на диске)

У файловой системы есть суперблок – там хранится метаинформация о файловой системе. Можно вывести одной из двух команд:
```bash
sudo dumpe2fs /dev/vdb1
sudo tune2fs -l /dev/vdb1
```

Там же есть информация о количестве индексных дескрипторов (inode)

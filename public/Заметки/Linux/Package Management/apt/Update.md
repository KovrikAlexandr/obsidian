Перед тем, как начать скачивать пакеты, `apt` требуется обновить свои локальные индексы, то есть метаинформацию о пакетах.

Кэш сохраняется в каталоге `/var/lib/apt/lists/`

1. apt скачивает формирует все URI из `/etc/apt/sources.list` и `/etc/apt/sources.list.d/`
2. Скачивает файл `InRelease`
3. Проверяет GPG подпись репозитория
4. Как-нибудь потом допишу

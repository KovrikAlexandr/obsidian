Чтобы изучить структуру пакета, можно скачать только `.deb` архив и не устанавливать его автоматически:
```bash
sudo apt download htop
```

Далее можем использовать инструменты:
- `dpkg` – менеджер пакетов
- `dpkg-deb` – инструмент для работы с самим файлом `.deb`
- `tar` – архиватор (без сжатия)
- `ar` – тоже архиватор, только более древний (Unix)

После скачивания можно изучить метаданные:
```bash
dpkg-deb -I htop_3.3.0-4build1_arm64.deb
```

В метаданных можно увидеть следующее:
```yml
Package: htop
Version: 3.3.0-4build1
Architecture: arm64
Maintainer: Ubuntu Developers <ubuntu-devel-discuss@lists.ubuntu.com>
Depends: libc6 (>= 2.38), libncursesw6 (>= 6), libnl-3-200 (>= 3.2.7), libnl-genl-3-200 (>= 3.2.7), libtinfo6 (>= 6)
```
- Видны название, версия, архитектура, автор и зависимости (другие пакеты с версиями)

Можно посмотреть список файлов, которые будут установлены:
```bash
dpkg-deb -c htop_3.3.0-4build1_arm64.deb
```

Распаковать архив в папку:
```bash
dpkg-deb -x htop_3.3.0-4build1_arm64.deb  htop-unpacked/
```

Далее можно проводить работу с `dpkg`

## Структура пакета
Тут в общем можно увидеть то же самое, только в голых архивах:
База:
```bash
dpkg -i pkg.deb # install
dpkg -r pkg # remove
dpkg -P pkg # purge (remove recursively with all configs)
dpkg -l # list all
dpkg -L pkg # List files installed by package
dpkg -I pkg.deb # Get info
```

`.deb` файл можно исследовать:
```bash
dpkg -I pkg.deb
```

Сам файл – архив формата `ar`. Это древний Unix-архиватор.
Базовое использование:
```bash
ar t file.a # List content
ar x file.a # extract all files to current dir
ar x file.a filename # extracts certain file
ar r file.a file1 file2 # add/replace files in archive
ar d filez filename # remove file from archive
```

Вытаскиваем содержимое пакета:
```bash 
ar x file.deb
```
Получаем три файла (два из них `.tar.xz` архивы):
```
debian-binary
control.tar.xz
data.tar.xz
```
- `debian-binary` – текст. Обычно версия формата пакета (не самого пакета).
- `control.tar.xz` – метаданные + `preinst`, `postinst`, `prerm` и `postrm` скрипты (просто bash)
- `data.tar.xz` – сама программа + доп. файлы с данными.

Работа с `tar` архивами:
```bash
tar -xf file.tar.xz # also works
```

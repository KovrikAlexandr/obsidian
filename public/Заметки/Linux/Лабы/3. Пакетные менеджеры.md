1. Выведите список всех подключенных репозитариев
```bash
sudo apt policy
```
![[Pasted image 20260309191338.png]]


2. Обновите локальные индексы пакетов в менеджере пакетов.
```bash
sudo apt update
```
![[Pasted image 20260309191324.png]]


3. Выведите информацию о метапакете build-essential:
```bash
sudo apt show build-essential
```
![[Pasted image 20260309191611.png]]
- Сам пакет почти ничего не весит, зато тянет за собой зависимости для сборки deb пакетов

4. Установите метапакет build-essential, при этом определите какие компоненты будут установлены, а какие обновлены.
```bash
sudo apt depends build-essential
sudo apt install build-essential # Перед тем, как прожать Y, можно посмотреть, что будет установлено и обновлено
```
![[Pasted image 20260309192434.png]]


5. Найдите пакет, в описании которого присутствует строка «clone with a bastard algorithm»
```bash
sudo apt search "clone with a bastard algorithm"
```
![[Pasted image 20260309192602.png]]


6. Скачайте в отдельную директорию в домашнем каталоге архив с исходными кодами найденного в п.5 пакета.
Добавляем `deb-src` в репозитории:
```yml
Types: deb deb-src
URIs: http://ports.ubuntu.com/ubuntu-ports/
Suites: noble noble-updates noble-backports
Components: main restricted universe multiverse
Signed-By: /usr/share/keyrings/ubuntu-archive-keyring.gpg

Types: deb deb-src
URIs: http://ports.ubuntu.com/ubuntu-ports/
Suites: noble-security
Components: main restricted universe multiverse
Signed-By: /usr/share/keyrings/ubuntu-archive-keyring.gpg
```
Делаем update
![[Pasted image 20260309193055.png]]

Создаём папку и качаем исходники:
```bash
mkdir -p ~/bastet-src
cd ~/bastet-src
sudo apt source bastet
```
![[Pasted image 20260309193218.png]]


7. Установите пакет из исходных кодов, скаченных в п.6
Читаем инструкцию по сборке:
![[Pasted image 20260309193730.png]]
Ставим зависимости:
```bash
sudo apt install libboost-dev libncurses-dev
# Пришлось еще libboost-program-options-dev поставить, чтобы скомпилировалось
```

Собираем по инструкции:
```bash
make
cp bastet /usr/local/bin
chgrp games /usr/local/bin/bastet
chmod g+s /usr/local/bin/bastet
touch /var/games/bastet.scores2
chgrp games /var/games/bastet.scores2
chmod 664 /var/games/bastet.scores2
```
![[Pasted image 20260309195102.png]]

Рубимся в тетрис с ублюдским алгоритмом:
![[Pasted image 20260309195736.png]]


8. Если в конфигурационном файле пакета нет параметров установки пакета в систему, то добавьте их, так, чтобы пакет устанавливался в /usr/local/bin и на него назначались права ---rwxr-xr-x. Проверьте выполнения этих директив.
9. Проверьте, что любой пользователь может запускать установленный пакет, но не тратьте на это более 5 минут

10. Создайте файл task10.log, в который выведите список всех установленных пакетов.
```bash
sudo apt list --installed > task10.log
```
![[Pasted image 20260309200116.png]]

10. Создайте файл task11.log, в который выведите список всех пакетов (зависимостей), необходимых для установки и работы компилятора gcc.
```bash
sudo apt-cache depends gcc | grep Depends | awk '{print $2}' > task11.log
```
![[Pasted image 20260309200442.png]]

11. Создайте файл task12.log, в который выведите список всех пакетов (зависимостей), установка которых требует установленного пакета libgpm2.
```bash
sudo apt-cache rdepends libgpm2 > task12.log
```
![[Pasted image 20260309200537.png]]

12. Создайте каталог localrepo в домашнем каталоге пользователя root и скопируйте в него c сайта http://snapshot.debian.org/package/htop/ пять разных версий пакета htop. Это можно сделать с помощью wget или просто передав файлы на виртуальную машину используя протокол ssh и утилиту scp.

13. Сгенерируйте в каталоге репозитория файл Packages, который будет содержать информацию о доступных пакетах в репозитории и файл Создайте файл Release, содержащий описание репозитория

14. Обновите кэш apt

15. Выведите список подключенных репозитариях и краткую информацию о них.

16. Создайте файл task16.log в который выведите список всех доступных версий htop
17. Установите предпоследнюю версию пакета

18. Скачайте из сетевого репозитория пакет nano. Пересоберите пакет таким образом, чтобы после его установки, появлялась возможность запустить редактор nano из любого каталога, введя команду `newnano`. Для работы с пакетом следует использовать dpkg-deb, а для установки dpkg. В файле протокола работы опишите использованные команды.

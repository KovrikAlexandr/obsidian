


## Хедеры

Хедеры HTTP запросов:

- `End-to-end` – протаскиваются от отправителя до получателя через все прокси

- `Hop-to-hop` – имеют смысл только в рамках соединения между двумя узлами (клиент и прокси, например). Примеры:
	- Connection
	- Keep-Alive
	- Upgrade
	По умолчанию `hop-to-hop` хедеры отрезаются при проксировании в nginx.

### Upgrade

Хедер доступен только в HTTP/1.1 (HTTP/1.0 ? ) и явным образом запрещён в HTTP/2.


### Connection





Для WebSocket используется такая связка:
```
Connection: Upgrade 
Upgrade: websocket
```

Для проксирования WebSocket используется хедер `Upgrade` для перехода с протокола HTTP/1.1 на WebSocket.

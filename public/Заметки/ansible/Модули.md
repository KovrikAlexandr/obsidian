Модуль – аналог функции. Готовая часть кода, которую можно параметризовать и вызвать

Запуск модуля через консоль:
```bash
ansible nginx -b -m shell -a 'chdir=/opt/nginx cmd="touch nginx.conf"'
```
- `-b` – (become) выполнить под sudo
- `-m` – модуль
- `-a` – arguments. Параметры запуска

Аналогично таска в плейбуке/роли:
```yml
- name: Touch nginx config
  become: true
  shell:
	chdir: '/opt/nginx'
	cmd: 'touch nginx.conf'
```

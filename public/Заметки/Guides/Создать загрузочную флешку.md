
### 1. Качаем `.iso` образ

После скачивания можно сравнить хеш сумму:
```bash
shasum -a 256 proxmox-ve_9.1-1.iso
```
- `-a` – алгоритм

### 2. Вставляем и находим флешку

Команда:
```bash
diskutil list
```

Пример нужного устройства:
```
/dev/disk21 (external, physical):
. . .
```

### 3. Загружаем `.iso` на флешку

```bash
sudo dd if=proxmox-ve_9.1-1.iso of=/dev/disk21 bs=1M conv=fdatasync status=progress
```
- `bs=1M` – размер блока (?)

Если:
```
dd: /dev/rdisk21: Resource busy
```
То можно посмотреть, какой процесс занимает его:
```bash
sudo lsof | grep /dev/disk22
```
Либо просто размаунтить:
```bash
diskutil unmountDisk /dev/disk21
```

После завершения сбрасываем кеш на физическое устройство:
```bash
sync
```

### 4. Извлечь флешку
```bash
diskutil eject /dev/disk21
```

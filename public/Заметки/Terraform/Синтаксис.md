HCL (HashiCorp Language) – язык конфигурации terraform

Пример создания ресурса:
```hcl
resource "yandex_vpc_network" "some_network" {
	name = "some-network"
}
```
- `yandex_vpc_network` – тип ресурса
- `name` – аттрибут ресурса
- `some_network` – имя конкретного экземпляра (де факто объекта)

Блоки в основном делятся на `resource` и `data`:
- `resource` – создаём ресурс
- `data` – подтягиваем существующий по имени

Примеры использования:
```yml
# Для data
# data.<тип ресурса>.<имя экземпляра>.<аттрибут>
data.yandex_compute_image.my_ubuntu.image_id

# Для resource
# <тип ресурса>.<имя экземпляра>.<аттрибут>
yandex_compute_disk.my_disk.id
```

Порядок объектов в коде не важен, Terraform сам умеет выстраивать цепочки зависимостей.
